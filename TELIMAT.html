02Müştəri saytı necə istifadə edir

Axtarış (Ctrl + K)

Yuxarıdakı böyüdücü. Məhsul adı, standart (C2TE, R4), səth (hamam) və ya məqalə tapır.

Məhsul köməkçisi

Sağ aşağıdakı düymə. "Hamamda su sızır" yazanda uyğun sistemi və məhsulları göstərir, tapmasa WhatsApp-a yönləndirir.

Sifariş düymələri

Məhsul, həll və hesablayıcıdakı düymələr hazır mətnlə WhatsApp-a gedir: məhsul adı, miqdar, sahə.

Sistem seçici

Hər həll səhifəsində qatlar məhsul səhifələrinə bağlıdır. "Siyahını kopyala" ustaya göndərmək üçündür.

Hesablayıcı

4 növ material. Nəticə kq, kisə sayı və tövsiyə olunan məhsuldur.

Əlaqə forması

Server lazım deyil: mesaj WhatsApp-da və ya e-poçt proqramında hazırlanır, müştəri göndərir.

WhatsApp nömrəsi: content/site.json faylında "whatsapp" sahəsi. Hazırda 994103470010 yazılıb — rəsmi nömrəni təsdiqləyin.

03Məzmunu yeniləmək

Dizayna toxunmadan bütün məzmun content/ qovluğundakı fayllarda dəyişdirilir. GitHub-da fayla klikləyin, qələm (Edit) işarəsini basın, dəyişin və Commit changes edin. 1–2 dəqiqə sonra sayt özü yenidən yığılır.

site.json

Telefon, e-poçt, ünvan, WhatsApp, sosial şəbəkələr, haqqımızda mətni, vakansiyalar

products.json

Bütün məhsullar: ad, təsvir, tətbiq sahələri, texniki cədvəl, TDS/SDS linkləri

categories.json

Kateqoriya adları, təsvirləri və rəngləri

systems.json

Həll yolları: qatlar, addımlar, köməkçinin açar sözləri

dealers.json

Dilerlər ölkə üzrə: ad və ünvan

news.json

Xəbərlər (ən yenisi yuxarıda)

references.json

Referans layihələr

grouts.json

32 dərz rəngi (ad və ekran rəngi)

blog/*.md

Bloq məqalələri, sadə mətn formatında

Yeni məhsul əlavə etmək

products.json-da mövcud məhsulun blokunu kopyalayın və dəyişin. Qısa forma:

{
 "slug": "izomax-yeni",
 "name": "IZOMAX® YENİ",
 "cat": "izolyasiya",
 "group": "Sement əsaslı",
 "short": "Qısa təsvir",
 "image": "https://.../sekil.png",
 "featured": false
},

slug səhifənin ünvanıdır (kiçik hərf, tire ilə). cat kateqoriya kodudur: yapisdirici, derz, izolyasiya, temir, istilik, zemin, suvaq, coatix, qatqi, qelib, astar, kur, mastik. Tam məlumat üçün "featured": true yazıb standard, classes, desc, areas, features, tech, consumption, tds, sds sahələrini əlavə edin (CERAMAX® FLEX nümunəsinə baxın).

Yeni bloq məqaləsi

content/blog/ qovluğunda yeni fayl yaradın, məsələn yeni-meqale.md:

---
title: Məqalənin başlığı
date: 2026-11-01
category: Bələdçi
excerpt: Bir-iki cümləlik qısa təsvir.
products: CERAMAX® FLEX, FUGAMAX® FLEX
---

04GitHub-da yayımlamaq

A. Tövsiyə olunan: avtomatik yığılma

  1. github.com/new — repozitoriya yaradın, məsələn mrfix-site.
  2. ZIP-i açın. mrfix-web qovluğunun içindəki hər şeyi (.github qovluğu daxil) repozitoriyaya yükləyin.
  3. Settings → Pages → Source: GitHub Actions seçin.
  4. Actions bölməsində "Saytı yığ və yayımla" işi yaşıl olanda sayt açılır: https://İSTİFADƏÇİ.github.io/mrfix-site/

Bundan sonra content/-da hər dəyişiklik saytı avtomatik yeniləyir.

Terminal ilə:

cd mrfix-web
git init
git add .
git commit -m "Mr.Fix yeni sayt"
git branch -M main
git remote add origin https://github.com/İSTİFADƏÇİ/mrfix-site.git
git push -u origin main
.github qovluğu nöqtə ilə başladığı üçün bəzi kompüterlərdə gizli görünür. Brauzerdən yükləyəndə görünmürsə, terminal üsulundan istifadə edin.

B. Sadə: hazır faylları yükləmək

ZIP-dəki _site qovluğu artıq yığılmış saytdır. Onun içindəkiləri boş repozitoriyaya yükləyin və Settings → Pages → Deploy from a branch → main / root seçin. Bu üsulda məzmun dəyişəndə saytı kompüterdə python3 build.py ilə yenidən yığmaq lazımdır.

404 səhifəsi

Sayt github.io/mrfix-site/ ünvanında olarkən site.json-da "base_path": "/mrfix-site/" yazın. mrfix.az domeninə keçəndə yenidən "/" edin.

05mrfix.az domenini bağlamaq

Əvvəlcə şəkilləri endirin. Məhsul və layihə şəkilləri hazırda köhnə saytdan (mrfix.az/site/assets/…) yüklənir. Domen dəyişəndə o ünvanlar işləməyəcək. Domeni keçirməzdən əvvəl kompüterdə python3 tools/download_images.py işə salın və yaranan static/img qovluğunu GitHub-a yükləyin. TDS/SDS PDF-lərini də yeni yerə köçürüb products.json-dakı linkləri yeniləyin.
  1. site.json-da "cname": "mrfix.az" və "base_path": "/" yazın.
  2. GitHub: Settings → Pages → Custom domain → mrfix.az.
  3. Domen panelində (DNS): 
    A      @    185.199.108.153
A      @    185.199.109.153
A      @    185.199.110.153
A      @    185.199.111.153
CNAME  www  İSTİFADƏÇİ.github.io
  4. DNS yenilənəndən sonra (bir neçə saat) Enforce HTTPS qutusunu işarələyin.
  5. Google Search Console-da https://mrfix.az/sitemap.xml faylını təqdim edin.

06Yayımdan əvvəl yoxlama siyahısı

  • Həll yollarındakı məhsul birləşmələrini və addımları texniki şöbə təsdiqlədi
  • WhatsApp nömrəsi və iş saatları düzgündür
  • Dərz rənglərinin ekran tonları rəng kartı ilə müqayisə olundu (grouts.json)
  • Hesablayıcıdakı sərfiyyat dəyərləri texniki vərəqələrlə uyğundur
  • 25 kq qablaşdırma bütün toz məhsullar üçün doğrudur
  • Bloq məqalələri texniki şöbə tərəfindən oxundu
  • Məhsul şəkilləri endirildi (tools/download_images.py)
  • Rəsmi loqo faylı varsa, static/assets/logo.svg və logo-white.svg ilə əvəz olundu
  • EN, RU, TR, UZ versiyaları üçün qərar verildi (hazırda yalnız AZ)
  • Telefonda və kompüterdə bütün səhifələr açılıb yoxlandı
